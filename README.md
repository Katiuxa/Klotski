# Klotski / Huarongdao

Puzle de bloques deslizantes.

## Web

https://katiuxa.github.io/Klotski/

Fuentes en `src/`. GitHub Pages las compila con Vite.

```bash
npm ci
npm run dev
```

## Android

Capacitor en `android/`. Versión **1.0.33**.

```bash
npm ci
npm run apk
```

Keystore de Play Store fuera de git.
